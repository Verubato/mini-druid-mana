# MiniDruidMana

Shows a mana bar while in cat/bear/boomkin form.

This is useful for:

- Stealth drinking so you know when to stop.
- In classic/tbc to know if you have enough mana to shift out and back to a different form.
- As feral/boomie to know if you have mana to throw out some off heals.

This is a brand new addon and features will be added over time.

Feedback and feature requests are more than welcome!
